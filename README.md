# InciDesk - Sistema de Gestión de Incidencias

## Descripción

Este proyecto fue desarrollado como parte de la práctica de preparación para la Hackathon. Su objetivo es facilitar el registro y la gestión de incidencias dentro de una institución.

## Tecnologías utilizadas

- Angular
- TypeScript
- HTML y CSS
- LocalStorage
- Bootstrap Icons

## Funcionalidades

- Registrar incidencias.
- Listar y visualizar incidencias.
- Editar y eliminar registros.
- Buscar por título.
- Filtrar por prioridad y estado.
- Visualizar estadísticas en el dashboard.

## Instalación

Instalar las dependencias:

`npm install`

Ejecutar el proyecto:

`ng serve`

Ingresar desde el navegador:

http://localhost:4200
